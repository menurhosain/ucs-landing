# WPUCS · Marketing UI Kit

Recreation of the **wpucs.com landing page** with the redesigned IA from the brief.

## Sections (in order)
1. **Header** — sticky top nav with logo, links, sign-in, Buy Now
2. **Hero** — H1 + subhead + dual CTAs + dashboard mockup with Block-Editor template grid
3. **Stats** — version / users / downloads / Google Fonts row
4. **Features** — 9 Block-Editor / countdown / newsletter / SEO feature cards
5. **Templates** — 22 of the 29 demo templates with category filters
6. **HowItWorks** — Install → Customize → Launch
7. **UseCases** — pre-launch, maintenance, product launches
8. **MidCTA** — dark navy CTA band
9. **Pricing** — yearly/lifetime toggle, 4 tiers per mode, money-back guarantee
10. **Footer** — RSTheme attribution, sitemap, payment badges

## Components
- `ui.jsx` — `Btn`, `Pill`, `Eyebrow`, `Section`, `Logo`
- `Header.jsx`, `Hero.jsx`, `Stats.jsx`, `Features.jsx`, `Templates.jsx`, `HowItWorks.jsx` (also exports `UseCases`, `MidCTA`), `Pricing.jsx`, `Footer.jsx`

Open `index.html` to view the kit.
